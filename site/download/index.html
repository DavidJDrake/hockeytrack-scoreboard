Verify it before you flash it

  1. Check the download is intact. This checksum comes from the same mirror as the image, so it only proves the download is intact, not where it came from:
  2. Check it against the checksum published with the GitHub Release, fetched from GitHub rather than this mirror (needs the GitHub CLI):
  3. Check it was built from this project's source by its release workflow, for this version's tag. This is the check that proves where the image came from:

If any check fails, do not flash the image.

Flash it

  1. Open Raspberry Pi Imager, choose your board, then Use custom and pick the downloaded file.
  2. When Imager asks whether to apply OS customization settings, choose No. The panel sets itself up and needs none of them, and they could turn on remote login or set a password the image was deliberately built without.
  3. Write it to the SD card, then follow Set up a new panel.
  4. On the very first start the screen can stay dark for up to a minute and a half while the panel sets its Wi-Fi country and joins your network. That is normal — leave it powered on.
