Scoreboards

Sign in to add a scoreboard panel to your account, choose the game it follows, or remove it. Accounts are by invitation.

    Claim a panel

    Type the code shown on the panel's screen.

    Set up a new panel

    1. Prepare an SD card with the scoreboard installed.
    2. Download the setup file and save it onto the card's boot partition.
    3. Open it there, and type your Wi-Fi name and password.
    4. Put the card in the panel and power it on. When it shows a code, claim it above.
