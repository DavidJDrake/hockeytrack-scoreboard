Scoreboards

Sign in to add a scoreboard panel to your account, choose the game it follows, or remove it. Accounts are by invitation.

    Claim a panel

    Type the code shown on the panel's screen.

    Set up a new panel

    1. Download the scoreboard image, verify it, and write it to an SD card with Raspberry Pi Imager.
    2. Download the setup file and save it onto the card's boot partition. It must be named exactly scoreboard-setup.txt. If you have downloaded it before, your browser may have added a number to the name; remove it.
    3. Open it there, and type your Wi-Fi name and password. Check the country= line too -- the panel's Wi-Fi stays switched off until it knows which country it is in.
    4. Put the card in the panel and power it on. Before claiming the code it shows, check the panel says "Waiting for" your own address -- if it says "Waiting to be claimed" instead, the setup file wasn't read.
